# AI Mock Interview Platform 🤖

A sophisticated AI-powered mock interview platform that helps candidates prepare for technical interviews through real-time feedback, facial expression analysis, and comprehensive performance evaluation.

## ✨ Features

- **AI-Powered Interviews**
  - Dynamic question generation based on job position
  - Real-time speech-to-text transcription
  - Intelligent answer analysis

- **Real-time Analysis**
  - Facial expression monitoring
  - Eye contact tracking
  - Voice tone analysis
  - Body language feedback

- **User Experience**
  - Dark/Light mode support
  - Responsive design
  - Intuitive interface
  - Real-time feedback
  - Progress tracking

- **Technical Features**
  - Google Gemini AI integration
  - Face detection with face-api.js
  - Speech recognition
  - Django backend
  - TailwindCSS styling

## 🛠️ Tech Stack

- **Frontend**
  - HTML5
  - TailwindCSS
  - JavaScript
  - face-api.js

- **Backend**
  - Django 5.0.2
  - Python 3.8+
  - Google Gemini AI
  - SQLite3

- **APIs & Services**
  - Google Gemini AI API
  - Web Speech API
  - MediaDevices API

## 📋 Prerequisites

- Python 3.8 or higher
- Node.js and npm
- Google Gemini API key
- Modern web browser with camera and microphone support


## 🌐 Usage

1. **Create Account/Login**
   - Visit the homepage
   - Sign up or log in

2. **Start Interview**
   - Enter job position and experience
   - Allow camera and microphone access
   - Start the interview session

3. **During Interview**
   - Answer questions verbally
   - Maintain eye contact with camera
   - View real-time transcription
   - Navigate through questions

4. **Review Results**
   - Get detailed feedback
   - View performance metrics
   - Receive improvement suggestions
